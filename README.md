# Navodaya Vijeta 5.0
Hindi JNVST Class 6 preparation app for Arush and Ayush.

## Build APK with GitHub Actions
1. Upload all files in this repository to GitHub.
2. Open Actions and run **Build Navodaya Vijeta APK** (or push to main).
3. Download the `navodaya-vijeta-debug-apk` artifact from the completed workflow run.

This is a debug APK for testing, not a Play Store release. Mock papers and generated questions are practice material, not official NVS papers. The offline doubt solver is rule-based, not generative AI.

## Deploy to Vercel
Import this repository into Vercel. The static site is served from `public`.
